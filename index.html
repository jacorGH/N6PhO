Your relay

Free shared relay

A relay carries the game when two networks can’t connect directly (strict home routers, mobile data). Your own relay is more reliable than the free shared one.

Direct invites then carry logins that expire within a day, so a friend on a strict network can still connect. Anyone holding that invite link could use your relay until then.

Setup guide: Cloudflare
  1. Sign up for a free account at dash.cloudflare.com (works from your phone).
  2. Open Realtime → TURN Server and create a TURN key. Keep its Key ID and API token.
  3. Open Workers & Pages → Create → start from the Hello World Worker, then Edit code. and paste it over everything, then Deploy.
  4. In the Worker’s Settings → Variables and Secrets, add three: TURN_KEY_ID, TURN_KEY_API_TOKEN and ACCESS_CODE (a passphrase you make up). Add the last two as secrets.
  5. Back here, choose Cloudflare, enter the Worker’s address and your access code, and tap Save and test.

The Worker only hands out logins that expire within a day, and only to someone with your access code. Check Cloudflare’s dashboard for its current free allowance.

Setup guide: your own server
  1. Create a free Ubuntu server, for example on Oracle Cloud’s Always Free tier.
  2. In the cloud firewall (on Oracle: the subnet’s Security List) allow UDP 3478, TCP 3478 and UDP 49160–49999.
  3. On the server run:
    curl -fsSLO relay/setup-coturn.sh && sudo bash setup-coturn.sh
  4. Open the link it prints on your phone. N6PhO saves the relay; tap Save and test.
